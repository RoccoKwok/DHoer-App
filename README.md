# Introduction
DHoer (Detector Helper) is a program designed to interface with App Inventor 2 for elderly individuals. The system tracks relevant metrics, such as battery level and alarm status, and is integrated into a fall detection solution. When a fall is detected via the user's walking stick, DHoer transmits a notification to designated relatives, alerting them to a potential injury.<br>
It associates with **DHoer-gadget** as a whole to do the function above.<br>
DHoer-gadget link: https://github.com/RoccoKwok/DHoer-Gadget<br>
You can continue editing the program by downloading the **.aia file**<br>
You can either download the **.abb or .apk file** to use the app directly.<br>
**REMEMBER! It can only be download via Android device.**
